대신 접수 결과 확인 · 0.3.1

테스트4·5·6의 접수 성공을 확인했습니다. 이 버전은 접수 완료와 송장번호 확인을 따로 표시하고, 이미 등록한 건의 번호를 대신 일자별조회에서 가져옵니다.

기존 확장 프로그램을 삭제하지 마세요. 기존 폴더에 파일을 덮어쓰고 새로고침해야 3건의 접수 기록이 유지됩니다. 이미 접수한 테스트4·5·6을 다시 등록하지 마세요.

연결 도구 0.3.1 다운로드

1. 기존 연결 도구 업데이트

  1. 새 ZIP의 압축을 풉니다.
  2. 실제접수테스트-0.3.1 폴더 안의 파일들을 전에 크롬에 등록했던 기존 확장 프로그램 폴더 안에 덮어씁니다.
  3. chrome://extensions에서 ‘상화 대신 실제접수 테스트’의 새로고침 ↻을 누릅니다.
  4. 우리 테스트 화면도 새로고침하고 연결·결과 확인을 누릅니다. 기존 성공 기록으로 등록 완료 3건·도착지 수정 필요 1건이 표시됩니다.

테스트 화면 열기

2. 이미 등록한 송장번호 가져오기

  1. 같은 크롬에서 대신 일자별조회를 열고 2026-10-06을 조회해 테스트4·5·6이 보이게 합니다.
  2. 우리 테스트 화면에서 각 건의 송장번호 가져오기를 누릅니다.
  3. 날짜·수화주명·수량·운임·운송구분이 맞는 1건만 연결합니다. 신규 전송 건은 전화번호와 지불방법도 대조합니다. 여러 후보가 있으면 직접 확인하도록 멈춥니다.

번호 조회 과정에서는 접수·인쇄·목록 체크를 실행하지 않습니다. 실제 일자별조회 화면의 표 구조가 다르면 안내를 표시하니 아래 확인결과 파일을 보내 주세요.

3. 발송데이터 자동 가져오기 연결 확인

대신 일자별조회 화면을 열어둔 채 우리 테스트 화면의 확인결과 파일 저장을 누르고 새 JSON을 전달해 주세요.

이번 확인결과에는 ‘전체’ 선택과 ‘엑셀저장’ 버튼의 연결 정보가 추가됩니다. 실제 엑셀저장이나 인쇄는 실행하지 않습니다. 기존 확인결과에는 접수 응답만 있어서 이 정보가 필요합니다.

운영용은 선택 여러 건 올리기 / 현재 조회 목록의 미등록 건 전체 올리기와, 대신 발송데이터를 기존 업로드·송장번호 연결·교차검증 기능으로 자동 전달하는 흐름으로 이어집니다. 이 연결은 아직 구현·실제 검증 중입니다.

현재는 로컬에서 1건씩 접수하는 테스트판입니다. 접수 시 해당 행을 체크한 뒤 초록색 등록(출력안함)만 누릅니다. 공동관할·미지정은 접수 후 마감관리에서 수기로 수정합니다. 택배·정기불가는 등록 안됨으로 표시합니다. 송장번호의 운영 DB 자동 저장·발송데이터 자동 가져오기·PDA 인쇄는 이번 버전에 포함하지 않습니다.
