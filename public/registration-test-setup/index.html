대신 실제 접수 테스트

화면 시연이 아니라 운영 출고정보 1건을 대신 전산으로 넘기는 테스트입니다. 대신에서 나온 송장번호를 일자별조회에서 대조해야 접수 확인으로 표시합니다.

이 화면은 대신에 로그인한 크롬에서 여세요. Codex 내부 브라우저에는 크롬 확장 프로그램이 연결되지 않습니다.

실제접수 연결 도구 다운로드

1. 연결 도구 설치

압축을 풀고 크롬 주소창에 chrome://extensions를 입력하세요. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 눌러 압축 안의 실제접수테스트 폴더를 선택하세요.

이전 ‘운송장 연결 확인’ 도구와 별개입니다. 이 도구는 로컬 테스트 화면과 대신 전산에만 연결됩니다.

2. 지정한 출고건 확인

2026-10-06 · 대신자동업로드테스트 · 대신 수량 1박스 · 착불 6,600원

실제 출고정보로 테스트 화면 열기 → 기존 계정으로 로그인 → 출고목록에서 날짜를 조회하고 아직 대신에 등록하지 않은 1건을 선택하세요. 화면과 체크리스트는 운영 사이트 그대로이며 데이터도 공유됩니다.

3. 대신으로 전달한 1건 확인·접수

연결·결과 확인 → 선택 1건 대신 등록 화면으로를 누르세요. 내용 확인 후 대신 엑셀일괄발행 화면에 파일 저장·찾기 없이 데이터가 들어갑니다.

대신 화면에서 거래처·도착지·수량·운임이 같은지 확인하고, 대신의 기존 등록 버튼으로 최종 접수하세요. 이번 연결 테스트는 마지막 접수 버튼을 자동으로 누르지 않습니다. 등록 시 인쇄 여부는 대신 화면의 기존 설정도 확인해 주세요.

4. 실제 대신 목록에 있는지 대조

테스트 화면의 연결·결과 확인을 누르면 대신이 응답한 실제 번호가 표시됩니다. 실제 등록 확인을 누르고, 열린 대신 일자별조회에서 접수일자를 조회한 뒤 다시 확인하세요.

번호와 수화주명이 실제 목록에서 일치해야 대신 목록에서 접수 확인됨으로 표시됩니다. 확장 프로그램을 눌러서도 상태를 확인할 수 있습니다.

응답이 끊기거나 결과를 확인하지 못하면 자동으로 재접수하지 않습니다. 기존 건의 중복 접수를 막기 위해 동일 출고번호는 다시 전송하지 않습니다.

이번 도구는 접수 연결 테스트입니다. 실제 송장번호를 운영 DB에 자동 저장하거나 PDA 체크로 인쇄하는 단계는 아직 연결하지 않았습니다.
