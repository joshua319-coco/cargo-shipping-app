대신 자동 등록 테스트 · 0.3.0

업로드 → 해당 행 체크 → 초록색 등록(출력안함)까지 자동 진행합니다. 파란색 등록 버튼은 사용하지 않습니다.

대신에 로그인한 크롬에서 업데이트하세요. 이전 확장 프로그램과 접수 이력을 유지하려면 기존 확장 프로그램을 삭제하지 마세요.

연결 도구 0.3.0 다운로드

1. 기존 연결 도구 업데이트

  1. 새 ZIP의 압축을 풉니다.
  2. 압축 안 실제접수테스트-0.3.0 폴더의 파일들을, 전에 크롬에 등록했던 기존 확장 프로그램 폴더 안에 덮어씁니다. 폴더 안에 새 폴더를 넣는 방식이 아닙니다.
  3. chrome://extensions에서 ‘상화 대신 실제접수 테스트’의 새로고침 ↻ 버튼을 누릅니다.
  4. 우리 테스트 화면도 새로고침하고 연결·결과 확인을 누릅니다. 버전이 0.3.0이어야 합니다.

처음 설치하는 경우에만 개발자 모드 → 압축해제된 확장 프로그램 로드 → 새 폴더를 선택하세요. 서로 다른 버전을 동시에 설치하지 마세요.

2. 아직 접수하지 않은 새 테스트 건 준비

날짜 2026-10-06, 이름 대신자동업로드테스트4처럼 ‘대신자동업로드테스트’ 뒤에 번호를 붙인 새 출고건을 사용하세요. 이미 대신에 접수한 테스트1·2·3은 다시 접수하지 마세요.

자동 등록 테스트 화면 열기

목록에서 아직 접수하지 않은 1건만 선택 → 선택 1건 자동 등록(출력안함) → 내용을 확인하면 자동으로 진행합니다. 화면과 출고정보는 운영 사이트와 공유됩니다.

3. 결과 확인

대신 처리 결과동작
정상 도착영업소체크 후 등록(출력안함)
공동관할·도착지 미지정등록 진행 → 도착지 수정 필요 건수와 거래처 표시 → 대신 마감관리에서 직접 수정
택배·정기불가등록 안됨 표시와 해당 사유 안내
응답 끊김·결과 불명확결과 확인 필요 표시. 대신 목록을 확인하며 자동 재접수하지 않음

결과는 약 3초마다 갱신됩니다. 실제 송장번호가 수신되어야 등록 완료로 표시합니다. 실제 등록 확인으로 대신 일자별조회의 번호·수화주명까지 대조할 수 있습니다.

확인결과 파일은 문제가 있을 때만 저장하면 됩니다. 기존 0.2.0에서 이미 전송했던 건은 새 버전이 소급해서 자동 등록하지 않습니다.

이번 버전은 로컬 자동 접수 테스트입니다. 영업소 자동 지정, 송장번호의 운영 DB 자동 저장, PDA 인쇄는 포함하지 않습니다. 실제 대신 화면의 등록(출력안함) 클릭까지는 새 테스트 건으로 확인해야 합니다.
