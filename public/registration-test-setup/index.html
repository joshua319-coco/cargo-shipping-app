대신 전산 연동 · 0.5.0

미등록 건 등록(출력안함) → 발송데이터 자동 반영까지 한 번에 진행합니다. 선택한 출고건 또는 현재 조회목록의 대신 전체를 대상으로 할 수 있습니다.

기존 확장 프로그램을 삭제하지 마세요. 기존 폴더에 새 파일을 덮어쓰고 새로고침하면 접수 기록이 유지됩니다.

연결 도구 0.5.0 다운로드

연결 도구 업데이트

  1. ZIP 압축을 풀고 대신전산연동-0.5.0 폴더 안의 파일들을 기존 확장 프로그램 폴더 안에 덮어씁니다.
  2. chrome://extensions에서 기존 ‘상화 대신 실제접수 테스트’의 새로고침 ↻을 누릅니다. 이름이 ‘상화 대신 전산 연동’으로 바뀝니다.
  3. 출고사이트도 새로고침하고 연결·결과 확인을 누릅니다. 같은 크롬에서 대신 전산에 로그인해 두세요.

대신 출고목록 열기

대신 전산 연동

  1. 출고일·검색 조건으로 목록을 확인합니다. 선택 연동은 목록 앞 체크박스로 대상 출고건을 고릅니다.
  2. 대상을 선택한 대신 출고건 또는 현재목록 대신 전체로 고르고 대신 전산 연동을 누릅니다.
  3. 기존 접수 여부를 먼저 조회한 뒤 미등록 건을 차례로 등록합니다. 초록색 등록(출력안함)만 사용합니다.
  4. 마지막으로 발송데이터를 가져와 송장번호와 송장검증을 갱신합니다. 공동관할·미지정은 등록 후 마감관리에서 수정할 건수로 안내합니다.

‘전체’는 현재 조회목록의 대신 건에만 적용합니다. 로젠 건은 포함하지 않습니다. 진행 중 나머지 등록 중지를 누르면 현재 건의 결과를 확인하고 남은 등록을 멈춥니다.

전산 데이터 새로고침

대신 전산에서 수량·운임·도착지를 직접 수정했다면 조회일을 고르고 전산 데이터 새로고침만 누르세요. 등록 없이 최신 엑셀 원본을 읽어 다시 대조합니다. 이미 연결된 송장번호는 출고정보를 수정해도 유지됩니다.

택배·정기불가로 등록 안됨이 확인된 건은 출고정보를 수정하고 수정한 등록 실패 건도 재시도를 체크한 뒤 연동하세요. 접수 결과가 불확실한 건은 재등록하지 않고 먼저 조회합니다. 이미 등록된 건은 데이터 조회에 실패해도 재등록하지 않습니다.

확인 및 수동 처리

  • 발화주 정보, 택배 주소, 화물 도착영업소를 포함한 원본 엑셀로 대조합니다.
  • 대신이 도착지 미지정 건을 엑셀에서 제외하면 해당 건을 안내합니다. 수정 후 새로고침하세요.
  • 기존 엑셀 직접 가져오기와 수동 등록용 엑셀 다운로드도 사용할 수 있습니다.
  • 문제 발생 시 출고목록의 연결 도구·확인결과를 펼쳐 확인결과 파일을 저장하세요.

로컬 확인판입니다. 하루 발송데이터 조회는 최대 1,000건입니다. 운영 사이트 배포와 별개이며 로젠 동작은 변경하지 않습니다.
