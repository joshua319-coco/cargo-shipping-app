대신 발송데이터 자동 가져오기 · 0.4.1

대신의 엑셀저장 원본을 자동으로 가져와 기존 출고목록의 송장번호 연결과 송장검증에 반영합니다. 발화주 정보, 택배 수화주 주소, 화물 도착영업소도 함께 가져옵니다.

기존 확장 프로그램을 삭제하지 마세요. 파일을 덮어쓰고 같은 확장 프로그램을 새로고침하면 기존 접수 기록이 유지됩니다. 이미 등록한 테스트 건은 다시 등록하지 않습니다.

연결 도구 0.4.1 다운로드

1. 기존 연결 도구 업데이트

  1. ZIP 압축을 풀고 실제접수테스트-0.4.1 폴더 안의 파일들을 기존 확장 프로그램 폴더 안에 덮어씁니다.
  2. chrome://extensions에서 ‘상화 대신 실제접수 테스트’의 새로고침 ↻을 누릅니다.
  3. 우리 테스트 화면도 새로고침하고 연결·결과 확인을 누릅니다. 버전 0.4.1이 표시됩니다.

테스트 화면 열기

2. 한 번에 발송데이터 가져오기

  1. 같은 크롬에서 대신 일자별조회를 열고 2026-10-06을 선택합니다. 조회 탭이 여러 개면 사용할 탭을 마지막으로 열어두세요.
  2. 우리 테스트 화면에서 대신 발송데이터 가져오기를 한 번 누릅니다. 출고건을 선택할 필요 없이 해당 날짜의 전체 발송데이터를 가져옵니다.
  3. 완료 후 출고목록의 운송장번호와 송장검증 탭에서 일치 여부를 확인합니다.

엑셀을 PC에 따로 저장하거나 다시 업로드할 필요가 없습니다. 가져오기 과정에서 재접수·인쇄는 실행하지 않습니다. 기존 수동 엑셀 업로드도 그대로 사용할 수 있습니다.

도착지 미지정 건도 등록과 송장번호 확인은 가능합니다. 다만 대신이 엑셀에서 제외한 건은 별도로 알려드립니다. 마감관리에서 도착지를 수정하고 다시 가져오면 전체 정보를 검증할 수 있습니다.

10월 7일 이후에도 기존 10월 6일 건으로 계속 확인합니다. 새로 등록할 필요 없이 대신 조회 날짜를 2026-10-06으로 맞춰주세요. 가져온 데이터는 6일에 저장하며 오늘 데이터는 유지합니다. 빈 번호·형식 오류·중복 오류가 뜨면 확인결과 파일 저장으로 문제 행이 기록된 파일을 전달해 주세요.

확인할 내용

  • 화물=정기, 선불=현불로 대조하며 택배(착불)처럼 합쳐진 값도 분리합니다.
  • 수량·운임·지불·운송상품·발화주·택배 주소·화물 도착영업소는 기존 송장검증에서 대조합니다.
  • 엑셀 데이터가 비어 있거나 다른 송장번호가 섞인 경우 기존 검증 데이터를 유지하고 안내합니다.

로컬 테스트판입니다. 발송데이터 가져오기는 하루 최대 1,000건이며 현재 테스트 날짜는 2026-10-06입니다. 등록 테스트는 여전히 1건씩이고 초록색 등록(출력안함)만 사용합니다. 운영용 여러 건 등록과 PDA 인쇄 자동화는 별도 작업입니다.
