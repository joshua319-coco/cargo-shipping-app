대신 실제 접수 테스트 · 0.2.0

새로 만든 테스트 3건을 한 건씩 대신 등록 화면으로 전달합니다. 기존 출고번호 제한을 없애 삭제 후 다시 만든 건도 선택할 수 있습니다.

대신에 로그인한 크롬에서 설치하고 테스트하세요. Codex 내부 브라우저에는 크롬 확장 프로그램이 연결되지 않습니다.

새 연결 도구 0.2.0 다운로드

1. 새 연결 도구 설치

이전 테스트 확장 프로그램을 삭제했다면 위 파일의 압축을 풀어 주세요. 크롬 주소창에 chrome://extensions 입력 → 개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다 → 압축 안의 실제접수테스트-0.2.0 폴더 선택.

설치 후 테스트 화면도 새로고침하세요.

2. 출고건 준비

출고등록에서 날짜를 2026-10-06으로 지정하고 아래 이름으로 저장하세요. 대신에서 도착지를 찾을 수 있도록 주소와 우편번호 또는 도착영업소를 정확히 입력하세요.

  • 대신자동업로드테스트1
  • 대신자동업로드테스트2
  • 대신자동업로드테스트3

새 테스트 화면 열기

기존 계정으로 로그인하면 해당 날짜와 테스트명으로 목록이 열립니다. 운영 사이트와 출고정보를 공유합니다.

3. 한 건 선택 → 대신 화면 확인

목록 왼쪽에서 1건만 선택 → 연결·결과 확인 → 선택 1건 대신 등록 화면으로를 누르세요. 대신 계정의 업로드 설정 로딩을 기다린 뒤 데이터를 전달합니다.

대신 화면에서 도착지·수량·운임을 확인하세요. 도착지 미지정이 나오면 먼저 대신 화면에서 수정하고, 테스트 화면의 도착지 다시 확인을 누르세요. 해결되지 않으면 확인결과 파일 저장으로 원인 확인에 필요한 파일을 받을 수 있습니다.

확인결과에는 전송한 주소·우편번호와 대신의 도착지 변환 상태가 포함됩니다. 로그인 정보나 전화번호는 수집하지 않습니다.

4. 실제 접수 확인

도착지가 정상이고 내용이 맞으면 대신의 기존 등록 버튼으로 접수하세요. 최종 등록과 인쇄 버튼은 이 도구가 자동으로 누르지 않습니다.

테스트 화면에서 연결·결과 확인 → 실제 번호가 나오면 실제 등록 확인 → 대신 일자별조회에서 해당 접수일자 조회 → 다시 실제 등록 확인. 송장번호와 수화주명이 모두 일치해야 접수 확인으로 표시됩니다.

같은 출고번호의 재전송은 막습니다. 연결이 끊겼다면 대신 일자별조회에서 접수 여부를 먼저 확인하세요. 확장 프로그램을 삭제하면 로컬 전송 이력도 지워지므로 이미 접수한 건은 다시 선택하지 마세요.

이번 버전은 로컬 접수 연결 테스트입니다. 운영 사이트 배포, 송장번호의 DB 자동 저장, PDA 자동 인쇄는 포함하지 않습니다.
