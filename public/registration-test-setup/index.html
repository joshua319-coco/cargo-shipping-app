대신 전산 연동 · 0.6.0

미등록 건 등록(출력안함) → 발송데이터 자동 반영까지 한 번에 진행합니다. 현재 조회목록에서 미등록 건만 자동으로 골라 처리합니다.

기존 확장 프로그램을 삭제하지 마세요. 기존 폴더에 새 파일을 덮어쓰고 새로고침하면 접수 기록이 유지됩니다.

연결 도구 0.6.0 다운로드

연결 도구 업데이트

  1. ZIP 압축을 풀고 대신전산연동-0.6.0 폴더 안의 파일들을 기존 확장 프로그램 폴더 안에 덮어씁니다.
  2. chrome://extensions에서 ‘상화 대신 전산 연동’(또는 이전 이름 ‘상화 대신 실제접수 테스트’)의 새로고침 ↻을 누릅니다. 추가 사이트 접근 권한 확인이 나오면 운영 출고사이트 주소를 확인하고 허용합니다.
  3. 출고사이트도 새로고침하고 같은 크롬에서 대신 전산에 로그인해 두세요. 연결은 버튼을 누르면 자동으로 확인합니다.

다른 PC에 처음 설치

  1. 이 페이지에서 ZIP을 내려받아 계속 보관할 폴더에 압축을 풉니다.
  2. 크롬에서 chrome://extensions를 열고 개발자 모드를 켭니다. 압축해제된 확장 프로그램 로드를 눌러 manifest.json이 들어 있는 대신전산연동-0.6.0 폴더를 선택합니다.
  3. 같은 크롬 프로필에서 운영 출고사이트와 대신 전산에 로그인합니다. 등록 이력은 출고사이트에서 공유되며 각 PC에서 따로 초기화할 필요가 없습니다.

대신 자동 연동을 사용할 PC와 브라우저 프로필마다 설치합니다. 로젠 엑셀 기능에는 이 연결 도구가 필요하지 않습니다.

대신 출고목록 열기

대신 전산 연동

  1. 출고목록의 전체 또는 대신 화면에서 출고일·검색 조건으로 현재 목록을 확인합니다.
  2. 오른쪽 대신 전산 연동을 누릅니다. 목록 체크나 대상 선택은 필요하지 않습니다.
  3. 기존 접수 여부를 먼저 조회한 뒤 미등록 건을 차례로 등록합니다. 초록색 등록(출력안함)만 사용합니다.
  4. 마지막으로 발송데이터를 가져와 송장번호와 송장검증을 갱신합니다. 공동관할·미지정은 등록 후 정보확인으로 표시합니다.

현재 조회목록의 대신 미등록 건에만 적용합니다. 로젠 건은 포함하지 않습니다. 진행 중 나머지 등록 중지를 누르면 현재 건의 결과를 확인하고 남은 등록을 멈춥니다.

대신 전산데이터 새로고침

대신 전산에서 수량·운임·도착지를 직접 수정했다면 왼쪽 대신 전산데이터 새로고침만 누르세요. 현재 조회목록의 출고일을 사용합니다. 등록 없이 최신 엑셀 원본을 읽어 다시 대조합니다. 이미 연결된 송장번호는 출고정보를 수정해도 유지됩니다.

택배·정기불가로 미등록으로 남은 건은 사유를 확인하고 출고정보를 수정한 뒤 다시 연동하세요. 접수 결과가 불확실한 건은 재등록하지 않고 먼저 조회합니다. 이미 등록된 건은 데이터 조회에 실패해도 재등록하지 않습니다.

전산등록 상태 버튼

  • 미등록: 누르면 해당 1건을 등록하는 확인창이 열립니다.
  • 등록완료: 접수와 발송정보 일치를 확인한 건입니다.
  • 정보확인: 누르면 불일치 항목, 우리 정보와 대신 정보, 도착지 수정 또는 접수 확인 사유를 볼 수 있습니다. 등록된 건을 다시 등록하지 않습니다.

로젠 전산등록 표시

로젠은 엑셀을 다운로드한 건이 등록완료로 표시됩니다. 아직 다운로드하지 않은 건은 미등록입니다. 발송데이터의 수량·운임·주소 등이 다르면 정보확인으로 표시하며, 송장번호가 아직 없다는 이유만으로 정보확인이 되지는 않습니다.

확인 및 수동 처리

  • 발화주 정보, 택배 주소, 화물 도착영업소를 포함한 원본 엑셀로 대조합니다.
  • 대신이 도착지 미지정 건을 엑셀에서 제외하면 해당 건을 안내합니다. 수정 후 새로고침하세요.
  • 수동으로 등록(엑셀)을 펼치면 대신 발송데이터 업로드, 선택 엑셀 다운로드, 현재 목록 전체 엑셀 다운로드를 사용할 수 있습니다.
  • 문제 발생 시 출고목록의 상세 결과·연결 설정를 펼쳐 확인결과 파일을 저장하세요.

운영 출고사이트에서 사용할 수 있는 연결 도구입니다. 새로 열거나 새로고침하면 오늘 날짜와 빈 업체명 검색으로 시작합니다. 하루 발송데이터 조회는 최대 1,000건이며 로젠 자동등록은 포함하지 않습니다.
