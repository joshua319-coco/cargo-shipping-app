업데이트 0.2.0 · 대신 등록 화면 확인 추가

대신 자동등록 연결 확인

이전 도구에서 빠졌던 엑셀 등록 화면의 처리 방식을 확인합니다.
이번에는 대신 엑셀일괄발행 화면만 확인해 주세요. 로젠을 다시 확인할 필요는 없습니다.

연결 확인 도구 다운로드
1

새 파일로 업데이트

위 파일을 내려받아 모두 압축 풀기를 누르세요. 새 연결확인도구 폴더 안의 파일과 vendor 폴더를 전부 복사해, 기존에 크롬에 등록했던 연결확인도구 폴더 안에 붙여넣고 덮어쓰기 해주세요.

기존 폴더 위치가 기억나지 않으면 아래 ‘처음 설치하거나 기존 폴더를 모를 때’를 펼쳐 주세요.

2

크롬에서 새로고침

주소창에 chrome://extensions를 입력하고, 상화 운송장 연결 확인 카드의 ↻ 새로고침을 누르세요.

확인 도구를 열었을 때 제목 옆에 0.2.0, 상태 목록에 대신 등록이 보이면 업데이트 완료입니다.

3

대신 엑셀일괄발행 화면 확인

대신 전산에 로그인한 뒤 엑셀일괄발행 화면 열기를 누르세요.

파일은 선택하지 않아도 됩니다. 그 화면에서 크롬의 퍼즐 아이콘 → 상화 운송장 연결 확인 → 현재 화면 확인을 누르세요.

4

결과 파일 보내기

확인 결과 파일 저장을 누르고, 내려받은 등록_연결확인.json을 진행 중인 대화에 첨부해 주세요.

‘일부 정보 저장됨’이어도 파일을 보내주세요. 이 표시는 자동 등록 가능 여부의 판정이 아니라 수집 상태입니다.

처음 설치하거나 기존 폴더를 모를 때
  1. 새 압축파일을 풀고 연결확인도구 폴더 위치를 확인하세요.
  2. chrome://extensions에서 개발자 모드를 켜세요.
  3. 기존 ‘상화 운송장 연결 확인’이 있으면 삭제한 뒤, 압축해제된 확장 프로그램을 로드합니다를 누르세요. 삭제하면 도구에 저장된 이전 확인 결과는 없어지지만 대신·로젠 데이터에는 영향이 없습니다.
  4. 새 연결확인도구 폴더를 선택하고, 위 3번부터 진행하세요.
기존 운송장 출력 연결 확인 방법

대신은 조회 → 일자별 조회, 로젠은 운송장 발행 미리보기 화면에서 도구의 현재 화면 확인을 누릅니다. 마지막 인쇄 버튼은 누르지 않아도 됩니다.

이미 보내주신 출력 정보가 있으므로 이번 등록 확인을 위해 이 과정을 반복할 필요는 없습니다.

확인하는 정보

등록 항목 이름, 버튼과 함수 이름, 처리 경로와 코드의 연결 구조입니다. 입력된 이름·전화번호·주소, 출고 목록, 로그인 정보, 코드 안의 일반 문자열 값은 결과에 포함하지 않습니다.

도구는 화면을 읽기만 합니다. 등록·인쇄·파일 업로드를 실행하지 않으며 결과를 외부로 자동 전송하지 않습니다. 자동 등록 기능은 아직 적용되지 않았습니다.
