프린터 컴퓨터에서 한 번 확인

운송장 자동출력 연결 확인

Codex 설치 없이, 기존 대신·로젠 전산의 출력 연결 방식을 확인합니다.
이 단계는 연결 확인용이며 아직 자동출력 기능은 아닙니다.

연결 확인 도구 다운로드
1

프린터 컴퓨터에서 압축 풀기

위 파일을 내려받아 마우스 오른쪽 버튼 → 모두 압축 풀기를 누르세요.

압축을 풀면 연결확인도구 폴더가 있습니다. 안에 manifest.json 파일이 있는 폴더입니다.

2

크롬에 확인 도구 넣기

  1. 크롬 주소창에 chrome://extensions를 입력하세요.
  2. 오른쪽 위 개발자 모드를 켜세요.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르세요.
  4. 방금 압축을 푼 연결확인도구 폴더를 선택하세요.

‘상화 운송장 연결 확인’이 목록에 나타나면 준비됐습니다.

3

두 사이트에서 한 번씩 확인

대신

평소 쓰는 대신 전산에 로그인하고 조회 → 일자별 조회 목록을 여세요.

로젠

평소처럼 운송장을 선택하고 운송장 발행 미리보기까지 여세요. 마지막 인쇄 버튼은 누르지 않아도 됩니다.

각 화면에서 크롬 오른쪽 위 퍼즐 모양 아이콘 → 상화 운송장 연결 확인 → 현재 화면 확인을 누르세요.

확인 창은 열려 있는 전산 화면을 읽습니다. 별도 빈 탭에서 실행하지 마세요.

4

결과 파일 보내기

대신과 로젠이 둘 다 확인됨으로 표시되면 확인 결과 파일 저장을 누르세요.

저장된 운송장_연결확인.json 파일을 지금 진행 중인 Codex 대화에 첨부해 주세요.

‘화면 확인 필요’가 계속 표시되더라도 결과 파일은 저장할 수 있습니다. 그 파일과 함께 표시된 문구를 알려주세요.

확인하는 정보

출력 버튼 이름, 프로그램 파일 경로, 출력 기능 이름입니다. 출고 목록 내용·입력칸·쿠키·로그인 저장정보는 수집 대상에 포함하지 않습니다.

이 도구는 인쇄하거나 출고 데이터를 바꾸지 않고, 결과를 외부로 자동 전송하지 않습니다. 확인이 끝나면 크롬 확장 프로그램 목록에서 삭제해도 됩니다.
